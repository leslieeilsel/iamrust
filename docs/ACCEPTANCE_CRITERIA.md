# v0.1 验收标准

本文只覆盖精简后的原生桌面 IM 范围。语音/视频、完整富媒体、移动/Web 客户端、自动更新、代码签名和 E2EE 不属于 v0.1 验收项。

## 账号与安全

1. 两个全新账号可以注册，并分别使用用户名或邮箱登录。
2. 客户端重启后可从系统凭据库恢复会话；退出、改密或远程撤销后，相应令牌不再可用。
3. 访问令牌不写入 SQLite 或普通配置；刷新令牌与可选缓存密钥进入系统凭据库。
4. 用户可以查看设备、撤销其他设备、修改昵称/签名，并清理本地数据。

## 好友、会话与群组

1. Alice 可以精确搜索 Bob、发送好友申请；Bob 可以接受或拒绝。
2. 好友可以发起单聊；联系人、会话摘要、未读数和最近活动能在同步后更新。
3. 用户可以创建群聊，并按服务端角色规则执行改名、邀请、移除、禁言、转让、退出或解散。
4. 非成员读取或发送群消息时，服务端拒绝请求，客户端显示可恢复的错误状态。

## 消息与离线恢复

1. 文本消息先显示 pending，再根据 ACK 变为 sent；服务端按 `client_message_id` 幂等。
2. 发送失败的消息可以重试或删除；断网和应用重启后，持久化 outbox 不重复也不丢失。
3. 历史消息可以向前分页，过期请求不会覆盖新会话；实时事件与同步页能去重。
4. 回复、撤回、逐条转发、回应、收藏、详情和本地搜索可以从 GPUI 界面完成。
5. 草稿按会话隔离，并在切换会话和重启后恢复。

## 原生桌面行为

1. 同一用户只运行一个主实例；重复启动会激活现有窗口。
2. 窗口位置、尺寸、最大化状态和主题偏好在重启后恢复。
3. 托盘可以显示主窗口与退出；正常关闭窗口时进入托盘（托盘初始化失败时安全退出）。
4. 通知总开关、声音、预览、隐私模式、会话免打扰、前台与自身消息抑制按设置生效。
5. macOS、Windows、Linux 分别按 [平台矩阵](./PLATFORM_MATRIX.md) 完成真实系统冒烟。

## 质量与候选包

1. `cargo fmt --all --check`、严格 Clippy、Rust 测试和 release build 通过。
2. 保留的旧版 Web 类型检查、Lint、单测和 Playwright 回归通过；这些测试不替代原生 UI 人工验收。
3. 数据库迁移、备份与恢复脚本通过；依赖策略没有阻断问题。
4. Release workflow 能生成目标平台候选包、SHA-256 校验和和 SPDX SBOM。
5. 未签名候选包必须明确标注，未完成真实平台冒烟前不得提升为稳定版。
