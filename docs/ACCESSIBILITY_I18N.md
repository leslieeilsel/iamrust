# 无障碍、键盘与国际化基线

- 核心流程必须可仅用键盘完成；交互控件使用原生元素或正确的 ARIA 角色与名称。
- 焦点环不得移除；弹窗打开后聚焦首个合理控件，Escape 关闭，并把焦点返回触发元素。
- 会话列表使用方向键移动，Enter 打开；消息菜单支持 Shift+F10 与 Menu 键。
- 状态不得只依靠颜色，正文与控件满足 WCAG 2.2 AA；高对比度主题至少达到 7:1 正文对比度。
- 尊重 `prefers-reduced-motion`，缩放至 200% 时不隐藏发送、返回、登录或安全操作。
- 用户可见字符串使用翻译键维护，首批语言为 `zh-CN` 与 `en-US`；日期、数字、文件大小和复数使用 `Intl`。
- 用户输入按 Unicode 字符而非字节计数；搜索覆盖中文、英文、数字和 Emoji。
- 三平台字体回退：系统 UI 字体优先，随后 `Inter`, `Segoe UI`, `PingFang SC`, `Microsoft YaHei`, sans-serif。
