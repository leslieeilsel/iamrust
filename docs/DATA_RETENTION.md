# 数据保留与删除规则

| 数据 | 默认期限 | 删除方式 |
| --- | --- | --- |
| 访问令牌 | 15 分钟 | 到期或撤销后失效 |
| 刷新令牌 | 30 天 | 轮换、退出、改密、远程退出或注销时撤销 |
| 密码重置令牌 | 15 分钟 | 使用、超限或到期后清理 |
| 未完成上传 | 24 小时 | 后台任务删除对象与授权记录 |
| 已发送消息 | 账号存续期；注销后最长 365 天 | 到期后批量匿名删除，法律留存除外 |
| 已上传附件 | 随引用消息；注销后最长 30 天 | 生命周期任务删除无引用对象 |
| 好友、草稿、会话设置 | 账号存续期 | 注销时删除 |
| 设备与安全审计 | 最后活动后 180 天 | 定期清理；调查中的记录可依法延长 |
| 服务日志 | 30 天 | 滚动删除，备份中最多再保留 30 天 |
| PostgreSQL 与对象存储备份 | 30 天 | 加密备份按代次淘汰 |
| 客户端媒体缓存 | 由用户控制 | 设置中随时清理；注销时清理 |

删除任务必须幂等，并记录成功数、失败数和剩余积压。备份中的已删除数据不会恢复到线上；其会随备份轮换自然清除。
