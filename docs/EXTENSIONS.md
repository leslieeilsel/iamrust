# 扩展平台评估

领域模型、应用用例和协议 crate 不依赖桌面 UI，可复用于 Android、iOS、Web 或机器人网关。移动端优先考虑 UniFFI 暴露 Rust 核心，UI 使用各平台原生框架；Web 端复用 REST/WebSocket DTO，但凭据改用 Secure、HttpOnly、SameSite Cookie，不能复制桌面 keyring 假设。

跨端同步继续使用单调事件游标；草稿、已读位置和会话设置已有服务端状态。新设备必须拥有独立刷新令牌族并可单独撤销。

机器人/插件 API 若实施，应使用独立 OAuth 客户端、按会话/动作授权、显式用户同意、速率限制和审计。插件不得获得数据库、Shell、任意文件系统或完整账号令牌。当前仓库只保留这一设计边界，不承诺已提供公共插件市场。
