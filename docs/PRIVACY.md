# I Am Rust 隐私说明

更新日期：2026-08-30

I Am Rust 只处理提供即时通讯所必需的数据：注册邮箱、用户名、密码哈希、公开资料、好友关系、设备会话、会话成员、消息、回执及用户主动上传的附件。密码、访问令牌和刷新令牌不会以明文写入服务端数据库；桌面端刷新令牌保存在操作系统凭据库中。

用户可以分别控制性别、生日、地区和在线状态对所有人、好友或仅自己的可见性，也可以关闭已读回执。隐身状态对其他用户统一显示为离线。通知隐私模式可隐藏系统通知中的发送者与消息内容。

设置中的“导出账号数据”会生成包含个人资料、好友关系、申请、会话和消息的 JSON 副本。注销账号需要再次输入密码和 `DELETE`；注销后登录凭据立即失效，公开资料被匿名化，好友关系被移除。为维护其他参与者的会话完整性，已发送消息会按数据保留规则继续保存，但不再关联可登录身份。

当前版本未提供端到端加密，不应将其用于传输国家秘密、支付凭据、医疗记录等高敏感数据。传输层在生产环境使用 HTTPS/WSS；服务运营者仍可能在履行服务、反滥用和故障恢复职责时访问服务端数据。

崩溃诊断默认脱敏，不包含密码、令牌或完整消息正文。用户可在发送前查看诊断导出内容。
