# I Am Rust 用户协议摘要

更新日期：2026-08-30

I Am Rust 是独立的开源即时通讯应用，不属于腾讯或 QQ，也不兼容 QQ 私有协议。用户不得利用服务骚扰他人、传播违法内容、恶意文件或实施未授权访问。

用户对自己发送的内容负责，并授予服务在提供投递、同步、备份和下载功能所必需范围内处理该内容的许可。举报、封禁和限流能力用于保护服务与用户；管理员操作应进入审计记录。

账号注销不可逆。注销前应先导出所需数据。已投递给其他参与者的消息可能继续保留并显示为“已注销用户”，具体期限见数据保留规则。

软件按开源许可证提供，不承诺永不中断。安全问题请按仓库安全策略私下报告，不要在公开 issue 中披露可利用细节。
